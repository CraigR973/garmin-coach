# Batch 372 — Home and the check-in: wording for Craig

5 Nov. **Draft — not signed off. Nothing in Batch 372 is merged.**

## 1. One ride pick, shown immediately

Home offers Easy Zone 2 and Tempo as soon as the morning is available, even before Read it, ahead of the non-medical reminder cards. The ride row does not repeat Approve & upload or Ignore while this pick is open. Those two ride choices and their safety rules are unchanged. The card states:

> No pick: the planned ride stays on Zwift.

The existing planned ride stays until he picks; the app does not silently choose a different ride. Other actions keep their existing Read it rule.

## 2. A shorter check-in

Symptoms come first, then the existing feel score. Its description is:

> Symptoms first, then how you feel. Add anything I should know.

The existing advice question and Yes, I did / Not this time buttons sit together above the note, without a separate card. No answer stays unknown. Quick flags and the second feel text box are folded under:

> More about how you feel

> Quick flags and a few words (optional)

Last night's setup and More remain available as before; blood pressure is still saved and checked by the existing health rule. Nothing saved is removed.

REM questions appear on the first morning after the week's actions were actually issued, including a midweek issue. They do not repeat through the week. The question's short description is:

> These actions were suggested for last night. Did you try them?

Tried it / Didn't try it / Not sure remain unchanged. Unknown is never counted as didn't try; nightly watch observations and existing evidence collection are unchanged. Other nights remain unknown for whether an action was tried, so evidence about which action helps will accumulate more slowly.

## 3. The ride is done

After all planned rides for the day are logged complete, Home replaces its morning instruction with:

> Done

> {sessions} logged.

For example, “Long Zone 2 logged.” The morning colour, recovery reading and reason stay; the stored morning and brief stay as written. A medical call keeps its warning and adds “Done. {sessions} logged.” below it. A completed easy ride does not hide an unfinished ride.

## 4. No plan, with something logged

The existing signed-off No plan loaded text also appears when a walk or strength session is logged. It takes priority over Rest is still the plan today. No new wording.

## 5. The smaller reference pages

Coach memory uses the existing friendly Written today / Written yesterday / Written on 5 Nov date helper, without seconds, in the user's timezone. The handover summary uses the same helper. Confirmed memory addresses the reader as you: for example, “Mark prefers morning rides” displays as “You prefer morning rides”. Stored statements and source quotes are unchanged; other people's subjects are not rewritten.

Handover's baseline table keeps the same figures with these headings:

> | Metric | Usual | Middle value | Lowest | Highest | Readings |

Usual is the existing arithmetic average; Middle value is the existing median. No figure or packet key changes.

Experiment cards put this label before the stored hypothesis, making clear that it is an idea under test:

> We're testing this idea:

No prompt text or version changes, paid calls, migration, deletion or hosting changes.

## Decisions made for this draft

- The planned ride remains the default; this batch changes the controls, not the coaching decision.
- REM is asked once, the morning after issue; ongoing nightly measurements still collect.
- Done requires every planned ride to be completed, so a warm-up or easy ride cannot hide another ride; medical warnings stay.
- Memory changes are display-only, with verb changes limited to an explicit owner subject; quotations stay exact.
